# 版式规范与排障

## 目录
- 默认版式
- 主图
- 字幕条
- 字体
- 可调参数
- 排障：症状 → 调哪个变量

## 默认版式

- 画布 3:4，默认 1440×1920（`--width` 改宽度，`--aspect` 改比例）。
- 每条字幕条高度 = 画布高 × 7.5%（1920 高时为 144px），条间距为 0。
- 默认 4 条字幕条，主图占 `1 − 4 × 7.5% = 70%`（1344px）。这与参考的视频字幕拼图 skill 一致。
- 每条字幕条只放**一行**文字。一句金句最长占 2 条，需要时在标点处拆成相邻两行，像电影字幕跨两帧。

## 主图

由下往上叠三层：

1. **背景**：封面铺满主图区域，缩小后做高斯模糊再放大（模糊半径约宽度的 7%），压暗 40%。
2. **封面**：保持原比例，不拉伸，居中，高度约为主图的 72%（`--cover-ratio` 调整），带柔和投影。
   封面像素小于显示尺寸时用 LANCZOS 放大，放大超过 2 倍再轻微锐化。
3. **署名**：封面下方两行：`《书名》`，以及 `作者 · 微信读书热门划线`。
   作者名会去掉微信读书的国别标签（如 `[哥]`），实心圆点 `•` 换成间隔号 `·`。

没有封面时，退化为深色渐变背景加大字书名，仍然可以出图，但要告诉用户。

## 字幕条

- 底色：从封面提取主色，压成明度很低的深色（保留色相，饱和度限制在 0.30–0.65；封面接近灰色时保持中性）。
- 相邻两条明暗差约 14%，条顶有一条细暗线，帮助眼睛分出每一条，同时保持"零间距"的观感。
- 文字：白色，黑色描边（宽度约字号的 6%，至少 2px），按墨迹居中。
- 字号：同一张卡里所有字幕条使用同一个字号 = 能让最宽一行放下的最大字号，范围是条高的 36%–44%
  （1920 高时约 52–63px）。因此一行最多大约 25 个汉字，一句最多大约 50 个汉字。
- 左右留白各约宽度的 4.5%。

## 字体

按顺序自动查找（`cardlib._font_candidates`）：

- Windows：微软雅黑粗体、微软雅黑、等线粗体、黑体、宋体
- macOS：苹方、华文黑体、冬青黑体
- Linux：Noto Sans CJK、文泉驿

指定字体用 `--font 路径`，或环境变量 `WEREAD_CARD_FONT`。指定的字体不存在会直接报错，不会悄悄换别的。
字体必须是用户有权使用的。渲染时会检查字体是否缺字，缺字会在输出里警告。

## 可调参数

| 参数 | 默认 | 作用 |
|---|---|---|
| `--width` | 1440 | 画布宽度，高度按比例算 |
| `--aspect` | 3:4 | 画布比例，如 4:5 |
| `--bands` | 4 | 每张卡的字幕条数（`prepare_quotes.py` 和 `render_card.py` 要一致） |
| `--flex` | 关 | 允许每张卡 3–6 条，主图占比随之变化 |
| `--cover-ratio` | 0.72 | 封面占主图高度的比例，封面很小可以调低到 0.6 |
| `--cover` | 无 | 手动指定封面图，覆盖 `book.json` 里的封面 |
| `--font` | 自动 | 指定字体文件 |
| `--format` | jpg | `png` 文字边缘更锐利，文件更大 |
| `--overwrite` | 关 | 允许覆盖已有成品；默认拒绝覆盖 |

## 排障：症状 → 调哪个变量

| 症状 | 原因 | 处理 |
|---|---|---|
| 封面发糊，QA 提示放大倍数高 | 封面原图太小（常见 250×357） | 调低 `--cover-ratio`；看 `book.json` 的 `cover_attempts` 有没有更大的版本；让用户手动给高清封面（`--cover`） |
| 渲染前报"太长放不下" | 这条划线超过 2 条字幕条 | 改用它的完整句子选项（如 `14.3`），或放弃这条 |
| 渲染前报"共占 N 条，需要正好 4 条" | 所选金句的条数加起来不是 4 | 换一条凑满；或用 `--flex` 允许 3–6 条 |
| 一句话在词中间断开 | 句子接近两行上限，没有标点位置可断 | 换一条；或取它的完整句子选项 |
| 字幕条文字偏小 | 同卡里有一行很满，拉低了全卡字号 | 换掉最长的那一条，让各行长度接近 |
| 缺字（方框） | 字体没有这个字 | 换字体（`--font`） |
| 底色偏亮、白字不清楚 | 封面主色异常 | QA 会警告；手动换封面或检查封面是否纯白 |
| 提示文件已存在 | 默认不覆盖 | 确认要替换再加 `--overwrite`，或换 `--out-dir` |

## 返工纪律

发现问题时只改对应的那一个变量，改完重跑渲染和质检。连续三轮仍不满意，换一组金句，
或者如实告诉用户限制在哪里（比如封面太小），不要无限微调。
